## Portfolio: Data Science & AI

| Projekt | Worum es geht | Kernergebnis |
|---|---|---|
| [**Trace Plan**](https://github.com/endritde/trace-plan) | Kostenprognose & Controlling-Cockpit für einen Haustechnik-Mittelständler statt „Vorjahr + 3 %“ | Fehlplanung −26 % (Ø 2022–2025), Frühwarnung mit einem Drittel der Fehlalarme |
